# ai-resume-evaluator
Secure, AI-driven candidate screening platform leveraging React, FastAPI, Groq LLM, and SQLite. Features strict PII-scrubbing middleware and OPA integration for secure, rule-based algorithmic hiring.

### Database
This project is configured to use a local **SQLite** database (`db.sqlite3`) for the Alpha Release. The database file and its journal are excluded from version control via `.gitignore` to protect privacy and prevent merge conflicts.
